Quick Setup

Build the page you want by dragging the four grouped actions into Stream Deck and configuring each key.

01

Install and restart Stream Deck

Stream Deck loads the native telemetry host with the plugin. No separate bridge or setup application is required.

02

Start AC EVO and enter a driving session

Live values appear when EVO exposes shared-memory telemetry. Keys intentionally show no data outside a usable session.

03

Drag the exact action you need

Use Telemetry for a selectable field, Tires for a four-corner overview, Lights for mode and indicator feedback, or Control Button for a mapped command.

04

Match control key bindings

For ignition, starter, pit limiter, or lights, use the same keyboard key in the plugin and AC EVO.

Troubleshooting

The plugin trusts native EVO telemetry. It shows no data instead of carrying stale values or inventing unsupported states.

  • Enter an active driving session before judging live values.
  • Restart Stream Deck if keys remain stale after EVO is already running.
  • Confirm the health endpoint reports the native host as healthy.
  • Confirm telemetry values change while the car is moving.
  • Match every control button to the same keyboard binding used in EVO.

Native-data boundary

Race-control states that EVO does not expose reliably are intentionally omitted from the initial release. There is no screen-reading fallback.

Privacy

Local-only telemetry

The plugin reads AC EVO shared memory locally and exposes diagnostics only on 127.0.0.1. Driving data and settings are not sent to external servers.

Support reports

When opening an issue, share only what you choose: Stream Deck and Windows versions, EVO version, car, track, session, and relevant local diagnostics.

Something not matching the sim?

Include the action, the value EVO showed at the same moment, and your session details.
